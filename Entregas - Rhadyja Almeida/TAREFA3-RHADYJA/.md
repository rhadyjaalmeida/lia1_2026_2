📌 Sobre o projeto

O ViaVision AI é um projeto de Visão Computacional desenvolvido para analisar imagens de vias e transformar informações visuais em dados úteis sobre condição da superfície e presença de buracos.

A proposta combina duas tarefas complementares:

classificação de imagens, para compreender a condição geral da via;

segmentação semântica, para localizar visualmente regiões de buracos.

O projeto foi estruturado em duas partes principais:

Treinamento e avaliação dos modelos no Google Colab;

Execução dos modelos em uma aplicação web, utilizando modelos exportados em ONNX.

O ViaVision AI é um projeto acadêmico e experimental. Ele não substitui inspeções técnicas ou avaliações de engenharia.

🎯 Problema

A fiscalização da qualidade de vias normalmente depende de inspeções visuais realizadas por pessoas e pode envolver:

grandes extensões de ruas e rodovias;

inspeções demoradas;

dificuldade de acompanhar mudanças ao longo do tempo;

dificuldade de transformar observações visuais em dados estruturados;

priorização manual de trechos que precisam de manutenção.

A Visão Computacional pode ajudar a automatizar parte desse processo, transformando imagens em informações mensuráveis e facilitando a análise de grandes volumes de dados visuais.

💡 Solução proposta

O ViaVision AI recebe imagens de vias e utiliza dois modelos de Inteligência Artificial para executar tarefas diferentes, porém complementares.

Modelo 1 — Classificação da qualidade da via

Responsável por analisar a imagem de forma global e identificar a classe de superfície/condição aprendida durante o treinamento.

Arquitetura: MobileNetV2 + Transfer Learning

O modelo retorna:

classe prevista;

confiança da previsão.

Modelo 2 — Segmentação semântica de buracos

Responsável por identificar, pixel a pixel, regiões correspondentes a buracos.

Arquitetura: U-Net com encoder MobileNetV2

O modelo permite obter:

máscara de segmentação;

região do buraco;

área relativa na imagem;

componentes conectados;

bounding boxes derivadas da máscara.

🗂️ Datasets

1. Road Traversing Knowledge — RTK

Utilizado para o modelo de classificação da qualidade da via.

🔗 Road Traversing Knowledge (RTK) Dataset — Kaggle

O notebook utiliza o dataset para aprender padrões relacionados à superfície e à condição visual das vias.

As classes utilizadas no treinamento são identificadas a partir da estrutura real dos dados disponíveis, evitando assumir uma quantidade fixa de classes sem verificar o conteúdo baixado.

2. Pothole Image Segmentation Dataset

Utilizado para o modelo de segmentação semântica de buracos.

🔗 Pothole Image Segmentation Dataset — Kaggle

As anotações são disponibilizadas em formato YOLOv8 Segmentation e convertidas automaticamente pelo notebook em máscaras rasterizadas.

Polígono YOLO
      ↓
Coordenadas normalizadas
      ↓
Conversão para pixels
      ↓
Máscara rasterizada
      ↓
Treinamento da U-Net

Para o modelo de segmentação desta versão:

0 = Background
1 = Pothole

Em português:

0 = Fundo
1 = Buraco

🔐 Prevenção de Data Leakage

Imagens de vias podem apresentar grande semelhança entre si, principalmente quando pertencem a sequências ou trajetos próximos.

Para reduzir o risco de data leakage, o projeto procura:

preservar divisões oficiais de treino e validação quando disponíveis;

evitar divisões aleatórias desnecessárias;

reduzir o risco de imagens relacionadas aparecerem simultaneamente em treino e validação.

Esse cuidado é importante para que as métricas representem melhor a capacidade real de generalização do modelo.

🧩 Modelo de segmentação

A segmentação utiliza uma arquitetura U-Net com encoder MobileNetV2.

Imagem
   ↓

   ↓

   ↓

O modelo classifica cada pixel como:

Fundo

Métricas utilizadas

IoU

Mean IoU

Dice Score

Essas métricas são mais adequadas para segmentação do que utilizar somente accuracy.

📦 Bounding Boxes a partir da segmentação

O modelo de segmentação produz uma máscara pixel a pixel.

A partir dessa máscara, o projeto utiliza componentes conectados para identificar regiões independentes e derivar bounding boxes.

Máscara
   ↓
Classe de interesse
   ↓
Componentes conectados
   ↓
Regiões independentes
   ↓
Bounding Boxes

Isso permite apresentar os buracos de forma visualmente intuitiva, mantendo a segmentação como fonte principal da informação.

📊 Índice de Prioridade Visual

O ViaVision AI também calcula um Índice de Prioridade Visual, de 0 a 100, combinando sinais extraídos pelos modelos.

O indicador pode considerar:

condição visual geral da via;

área relativa ocupada por buracos;

quantidade de regiões identificadas.

Importante: esse índice é uma heurística visual e operacional. Ele não representa profundidade do buraco, área física em metros quadrados, risco estrutural ou avaliação de engenharia.

📦 Exportação ONNX

Os modelos treinados podem ser exportados para o formato ONNX, permitindo sua execução fora do ambiente Python.

TensorFlow / Keras
       ↓
      ONNX
       ↓
  ONNX Runtime
       ↓

Isso desacopla a etapa de treinamento da etapa de inferência.

Função de cada arquivo

Arquivo

Função

⚠️ Limitações

O modelo de segmentação atual é especializado em buracos.

A área calculada é relativa à imagem e não representa metros quadrados.

O projeto não estima corretamente a profundidade de buracos a partir de uma única imagem RGB.

O sistema não substitui inspeções técnicas ou avaliações de engenharia.

Mudanças de iluminação, câmera, região e tipo de pavimento podem afetar a generalização.

O Índice de Prioridade Visual precisa de calibração com dados reais antes de qualquer uso operacional.
